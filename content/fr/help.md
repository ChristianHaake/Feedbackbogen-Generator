# Aide

## Créer une grille

Recherchez un critère, ouvrez sa catégorie et sélectionnez les éléments pertinents. Ajoutez vos propres critères ou choisissez un format de production. Réglez le barème de chaque catégorie, le titre et les champs d’en-tête et de pied de page. Réorganisez la sélection avec les flèches. Vérifiez l’aperçu ou choisissez le mode liste de contrôle.

## Sauvegarder et exporter

Le navigateur conserve le travail localement. Téléchargez la configuration JSON pour une sauvegarde durable et modifiable. À l’ouverture, un import valide demande confirmation avant de remplacer le travail. Un fichier invalide laisse la grille intacte. En cas de problème de récupération, téléchargez les données originales avant de confirmer un import ou une réinitialisation. Réinitialiser restaure la grille par défaut.

Limites : 5 Mo par fichier JSON, 2 000 caractères par texte, 50 champs d’en-tête, 1 000 critères sélectionnés ou personnalisés et 200 catégories personnalisées. Importer une autre langue recharge l’application dans cette langue.

Choisissez le PDF pour imprimer, le PDF remplissable pour évaluer à l’écran, DOCX ou ODT pour modifier la grille, XLSX pour l’analyse tabulaire sans mise en page. Le premier export PDF nécessite une connexion pour les polices. Pour des caractères non pris en charge, utilisez DOCX ou ODT.
