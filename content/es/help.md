# Ayuda

## Crear una ficha

Busca un criterio y selecciónalo en los resultados, o explora las categorías. Añade criterios propios o elige un formato de producto. Ajusta la escala de cada categoría, el título, la cabecera y el pie. Reordena los criterios con las flechas. Comprueba la vista previa o elige el modo «Lista de verificación».

## Guardar y exportar

El navegador guarda el trabajo localmente. Descarga la configuración JSON para conservar una copia editable. Al abrir un proyecto válido, se pide confirmación antes de sustituir el trabajo. Un archivo no válido deja la ficha intacta. Si falla la recuperación, descarga los datos originales antes de confirmar una importación o un restablecimiento. Restablecer recupera la ficha inicial.

Límites: 5 MB por archivo JSON, 2.000 caracteres por texto, 50 campos de cabecera, 1.000 criterios seleccionados o propios y 200 categorías propias. Si importas un archivo de otro idioma, la aplicación se recarga en ese idioma.

Elige PDF para imprimir, PDF rellenable para evaluar en pantalla, DOCX u ODT para editar el documento y XLSX para analizar tablas sin el diseño del documento. La primera vez que exportes un PDF, necesitarás conexión para descargar las fuentes. Para caracteres incompatibles, utiliza DOCX u ODT.
