# Help

## Create a sheet

Search for a criterion and select it in the results, or browse by category. Add your own criteria or select a product format. Choose a scale per category and adjust the title, header fields and footer. Use the arrows in the selection to change the order. Preview shows the result immediately. Switch to checklist mode for a sheet without ratings.

## Save, restore and export

The browser saves work locally. Download the configuration as JSON for a durable, editable backup. Open it again through the editor. A valid import replaces existing work after confirmation. An invalid import leaves it intact. When recovery is offered, download the original data before importing a corrected file or resetting. Reset restores the default sheet.

A JSON file may contain up to 5 MB, with up to 2,000 characters per text, 50 header fields, 1,000 selected or custom criteria and 200 custom categories. An import in another language switches the interface and reloads the app.

Choose “Printable PDF” for printing, “Fillable PDF” for electronic ratings, DOCX or ODT to edit the document, or XLSX for tabular analysis. XLSX excludes the document layout. The first PDF export needs a connection to load the fonts. For unavailable characters, export DOCX or ODT.
