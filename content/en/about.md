# About the project

This open source tool helps teachers and trainers design transparent feedback and assessment sheets. Explicit criteria help learners understand expectations, reflect on their work and use feedback throughout learning.

Christian Haake and Anna Hegermann designed the first version. Barbara Ehlerding, Ingo Engelhaupt, Ludge Hamm, Michael Jäkel and Ben Quinkenstein contributed to criteria and structure. Christian Haake and Ira Fabri implemented the generator.
